# 8. Progression: none in v0

Status: Accepted

Date: 2026-11-05

## Context

Progression is large in scope but the ability effects themselves are needed to test systems.

## Decision

No progression in v0. A basic ability system exists with values edited in the debug panel.

## Alternatives considered

- Full XP and skill-point progression: parked in the backlog.

## Consequences

- Skills and augmentations are modifiers, so progression can be added later.
- See [abilities](../game/abilities.md).
