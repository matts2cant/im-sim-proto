# 15. Inventory: Deus Ex 1 grid

Status: Accepted

Date: 2026-11-05

## Context

Matches the inspiration and adds meaningful carrying decisions.

## Decision

Use a 6x5 grid with item footprints, no rotation, stacking consumables and a 10-slot belt.

## Alternatives considered

- Slot or weight-based inventory.
- Grid with rotation: parked.

## Consequences

- Pure grid logic is unit-testable.
- See [inventory](../game/inventory.md).
