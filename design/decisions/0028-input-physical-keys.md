# 28. Input: physical-key bindings

Status: Accepted

Date: 2026-11-05

## Context

Bindings should keep their positions across keyboard layouts.

## Decision

Bind actions by physical key, with QWERTY as the reference.

## Alternatives considered

- Bind by character: positions shift on other layouts.

## Consequences

- Gamepad and rebinding are in the [backlog](../backlog.md).
- See [controls](../game/controls.md).
