# 30. Code conventions

Status: Accepted

Date: 2026-11-05

## Context

Agents and humans need consistent rules to keep the codebase testable.

## Decision

Feature folders; typing as error (untyped_declaration); composition over inheritance; exactly three autoloads; signals for local events and stimuli for world events; gdtoolkit format and lint in a pre-commit hook.

## Alternatives considered

- Folders by file type.
- Inheritance-heavy entity hierarchy.

## Consequences

- See [conventions](../tech/conventions.md).
