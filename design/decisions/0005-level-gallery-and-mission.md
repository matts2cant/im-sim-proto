# 5. Level structure: test gallery plus mission area

Status: Accepted

Date: 2026-11-05

## Context

Each system needs an isolated space for testing, but the point of an immersive sim is systems combining.

## Decision

Build both: a hub with a test gallery (one room per system) and one small mission area.

## Alternatives considered

- Gallery only: tests systems but not their combination.
- Mission only: harder to test systems in isolation.

## Consequences

- Rooms double as manual test spaces.
- The mission (M9) validates that systems combine.
