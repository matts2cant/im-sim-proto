# Controls

Milestone: M0 (input map); actions added as features land.

## Purpose

Define the input scheme. Bindings are by physical key (QWERTY reference), so other layouts keep the same positions.

## Bindings

| Input | Action |
|---|---|
| W A S D | Move |
| Ctrl | Crouch |
| Shift | Sprint |
| Space | Jump / mantle |
| E | Use / pick up / carry |
| R | Reload |
| Q | Drop / throw |
| I | Inventory |
| 1-0 | Belt slots |
| F1-F4, F6 | Augmentations |
| F5 | Quicksave (M6) |
| F9 | Quickload (M6) |
| ` (QuoteLeft) | Debug panel |
| Mouse look | Look |
| LMB | Use item / fire |
| RMB | Alt |
